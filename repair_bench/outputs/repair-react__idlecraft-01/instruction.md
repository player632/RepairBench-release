# Something is off with my idle lumberjack game

Hey, I've been playing this idle game where my character chops trees, queues up tasks and keeps going while I'm away, and lately a bunch of things feel broken. Listing what I noticed, roughly from most annoying to least:

Not every defect is necessarily mentioned in the reports. Behaviors you break while fixing other things still count against you.

1. **Progress disappears when I close the tab.** I used to be able to just reopen the browser later and continue where I left off. Now, unless I manually use the export option first, everything is gone when I come back. It feels like the game stopped keeping a local save on its own.

2. **My task queue gets stuck on the first task.** I queued two things in order: first a tree-chopping task, then one of those growth-boost tasks that speeds up tree regrowth. The second one never starts — the character just keeps chopping forever and the boost sits there untouched. Re-adding the tasks changes nothing.

3. **The wrong item lands in my stash.** When a tree finally falls, I expect a raw log. Lately I get the processed plank instead. I didn't craft anything — it just shows up.

4. **Coming back after a long break barely heals my character.** I left the game running overnight and expected to be fully recovered by morning; now only a tiny sliver of health comes back. Regeneration feels almost frozen while I'm away.

5. **Chopping doesn't resume after the forest grows back.** If I empty out an area completely, chopping pauses, which is fair. But once fresh trees have actually grown in, nothing restarts by itself — I have to manually kick it off again every single time.

6. **The very first task I queue never starts.** When the queue is empty and I add one task, it just sits there marked as queued. Nothing happens until I add a second task; then suddenly things start moving.

Two more things I'm unsure about — maybe they're normal?

- I can't select the oak trees at all. Clicking one only shows a notice that my chopping level isn't high enough. A friend says oaks should be available early, so is the skill system broken or am I missing something?
- When I export my save, the text is a wall of scrambled characters. It looks corrupted to me, but maybe that's just how it's supposed to look?

Other than that the game seems to run fine: the numbers tick along, the interface looks normal, and I don't see any errors. I mostly play in short sessions and rely on the "keep going while I'm away" part, so the healing and the queue stuff hurt the most. Please help me figure out what's going on.
