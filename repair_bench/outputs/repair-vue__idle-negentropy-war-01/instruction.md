# idle-negentropy-war — 熵减战争多处机制异常

熵减战争（idle-negentropy-war）是一款浏览器单机科幻放置游戏（Vue 3 + Element Plus + Pinia + Vite）：玩家指挥文明对抗宇宙熵增——建造原子排序器等设施产出能量/物质/知识，解锁科技树，推进六个阶段的熵减进程，派遣探测器探索宇宙遗迹、合成稀有碎片，达成成就获取奖励；游戏计时由后台 worker 驱动，进度加密保存在浏览器本地。项目在 `npm install` 之后用 `npm run build` 构建，产物输出到 `docs/` 目录，静态托管该目录即可运行，无后端、无运行时网络依赖。

QA 收集了一批玩家报告，引述如下。请注意：

- 大多数报告描述了真实、可复现的缺陷，各自有独立的根因；根因所在的文件可能与症状出现的界面不同。
- 至少有一份报告描述的是正常行为或环境误报，动手修改之前请先核实。
- 并非所有缺陷都有报告提及。修复过程中破坏的其他行为同样会计入失败。
- Not every defect is necessarily mentioned in the reports. Behaviors you break while fixing other things still count against you.

## 用户报告

1. **开局能量少了**：新建存档刚进游戏，能量只有 90。我记得以前开局是 100 能量起步，其他资源倒是没变。
2. **能量产出变慢了**：开着默认的原子排序器挂了一会儿，能量的增长速度大概只有预期的一半，物质和别的产出看起来正常。
3. **熵减进度涨得不对**：点一次原子排序阶段的熵减操作，进度条涨的数值和老版本对不上，涨得比预期多了。
4. **宇宙遗迹探索按钮点不了**：我攒了 1000 出头的能量去派遣"宇宙遗迹"探索，按钮却显示资源不足。知识肯定是够的，以前这个价位是能出发的。
5. **造第二个建筑比预期贵**：造第二个原子排序器的时候，实际扣掉的能量比按花费公式算出来的要多，像是成长系数被调高了。
6. **碎片合成卡边界**：遗迹碎片攒到刚好够合成的数量时，合成就是不生效；多攒几个反而又能合成了。
7. **成就奖励缩水**："能量大师"成就达成后领取，到手的能量奖励只有以前的一半。

另有两份报告经复核为误报或环境行为，不需要修复：

8. （诱饵）疑似遭遇黑暗森林打击：有玩家担心坐标暴露引来降维打击、事件系统异常。经核实，开局阶段文明等级与暴露值都远未达到触发条件，事件列表为空属于正常现象。
9. （诱饵）存档疑似损坏：有玩家在本地存储里看到一串看不懂的乱码，怀疑存档损坏。经核实，存档本来就是加密存储的，能看到加密字符串属于正常现象。

## 验收口径

- 游戏在浏览器中正常启动，建造、科技、熵减、探索、合成、成就、事件各面板可用。
- 新存档的初始资源与设定一致。
- 设施产出按 数量 × 等级 × 科技效率 × 阶段加成 的既定公式结算。
- 科技解锁消耗与科技定义的成本一致。
- 熵减操作的进度增长与阶段效率一致，消耗与阶段成本一致。
- 探索派遣的成本判定与探索目标定义一致。
- 建筑建造花费按既定的数量成长系数递增；升级花费按既定的等级成长系数递增。
- 碎片合成在碎片恰好足够时可以正常进行。
- 成就达成判定与奖励结算符合成就定义。
- 后台计时按既定频率驱动游戏时间。
- 存档加密保存与读取链路完好。
