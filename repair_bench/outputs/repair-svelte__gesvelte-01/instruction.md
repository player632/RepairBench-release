# 我们内部那个表单搭建工具，最近好几处不对劲

我们组天天用的是一套网页版的表单搭建器（内部叫 geSvelte）。一共四个页面：首页是产品介绍，中间一排九张卡片；**「Stage」那一页才是干活的**——中间一个标题「Customize a New Form」，底下一个叫「New Form」的空面板（面板上写着 "This is where new fields should populate"），再底下一个「Edit Form」按钮；点了它右边会滑出一个抽屉，里面有「Add Checkbox」「Add Radio」「Add Input」「Add Button」四个按钮，往面板里加字段，加出来的每个字段在抽屉里都列成一行，行上可以点「Key 1」这种名字把它的字段编辑器打开，编辑器里能改标题、改选项、加选项、删选项；第三个页面「Docs」摆着两个现成的表单（「Login Here」和「Register a New Account」）；第四个页面「About」是团队介绍。顶栏是 Home / Stage / GitHub 三个链接，页脚有一行许可声明。

最近升级完之后好几个地方不对劲。我们组没人会写前端，只能把眼睛看到的现象照实说出来，麻烦你们从头查一遍、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容，甚至根本不知道那是个毛病。所以请你们自己把整套东西从里到外过一遍，别只盯着我列出来的这几条改；修别的问题时弄坏的行为，同样会算在你们头上。

## 我们确实碰到的问题

1. 在右边抽屉里新建一个单选组，然后点它那一行打开字段编辑器，点编辑器里的「Add」想给这个组再添一个选项——**行没多出来**，编辑器里的选项数还是原来那两个，页面上那个单选组也没变。浏览器控制台里同时报了一个错。多点几次也一样。

2. 还是那个字段编辑器：把某个选项的名字改掉（比如把 "Option 1" 打成 "Zebra"），**编辑器输入框里显示的确实是我打的新名字**，可是关掉编辑器回到页面，那个单选组显示的选项文字还是老的 "Option 1"。等于我白改了一遍。奇怪的是编辑器里改「Field Value」那一栏倒是能生效，只有改单个选项名字这一栏不行。

3. 新建出来的单选组，**默认选中的是最后一个选项，不是第一个**。我们的表单一向是默认选中第一项的，现在每次都得手动点回去。复选框组没这个问题。

4. 右边那个抽屉，**关掉的时候是「啪」一下直接消失的**，原来那个往右边滑出去的动画没有了；打开的时候滑入倒还在。看着像是掉了一半。

5. 「Docs」页那两个现成表单里，**密码框不再打点了**：我输入什么就明文显示什么，用户名框和密码框看起来一模一样。「Register a New Account」那半边两个密码框（还有确认密码那个）也是这样。

## 另外两件我们拿不准算不算毛病的事

6. 「Docs」页两个表单底部各有一个按钮，「Log in Now」和「Create Account」，**点了完全没反应**：不跳转、不提示、也不刷新。是不是登录功能坏了一半、只做了一半没做完？要不要我们把它接上？

7. 「Stage」页那个**「生成的代码预览」好像不见了**：以前记得能在页面下方看到一段实时生成的表单代码，现在整页都找不到。是被谁删了，还是本来就要点什么地方才出来？

## 环境说明

- 这个工具跑起来**不需要外网，也不需要任何后台服务**：所有表单状态都是浏览器里当场算出来的，没有接口。我们这边是拔了网线试的，页面自己一个外部请求都没发出去，也没有弹新窗口；原来那几个外部字体、外部仓库链接和外部许可文本链接都已经换成本地的 inert 占位页或者直接去掉了，字体也换成了系统自带的，所以任何「联网去取」的修法在这儿都不会生效，也不应该生效。
- 浏览器窗口是按 **1440×900** 试的，桌面尺寸，语言 en-US、时区 UTC。上面每一条现象都是在这个尺寸下看出来的，换个尺寸现象可能不一样。
- 每一项检查都是从一个**全新的页面**重新开始的：上一屏点过的按钮、开过的抽屉、打开过的编辑器、加过的字段都不会带到下一屏，本地存储里也不会留着上一次跑剩下的东西，地址栏也不会被上一屏改掉。所以「靠记住上次的状态蒙对」这种修法不管用。
- 页面里挂了一小段给自动化验收用的**只读探针**（记录页面有没有起来、有没有往外发请求、有没有报错、有没有留下存储或全局残留），请**不要删掉它、不要改名、也不要让它去读写业务状态**；我们看不出你们动了它，但验收会。
- 上面全是使用者视角的原话。我们不会去翻代码，也没本事告诉你们原因在哪儿、该改哪个文件；哪几条是真毛病、哪几条本来就是设计如此（第 6、7 条就有可能是我们自己想多了），得你们自己判断。
- 抽屉关掉那个动画是**整整一秒**的滑动，不是瞬间的；要判断它到底还在不在，得在关掉的半路上看一眼，光看最后有没有消失是看不出来的。
- 改完以后整套东西还得能**照常打包出来**，别为了绕过现象把功能整块删掉、把字段类型去掉、把选项写死成常量、或者按检查项做特判——那样我们会当成新毛病算在你们头上。
