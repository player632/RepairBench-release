# 这套卡车存档编辑器最近有好几处不对劲

我们几个玩 ETS2／ATS 的人一直在用的那套存档编辑器（先选档案、再选存档，然后改卡车、挂车、档案那几页，每个操作都是一个小弹窗，弹窗底下点 Apply 生效）最近有好几处看着不对劲。我不写代码，只能把眼睛看到的照实说出来，麻烦你们帮着查一查、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容；也有些地方我们以为是坏了、其实是它本来就该那样。所以请你们自己把整套东西从头到尾过一遍，别只盯着我列出来的这几条，也别看见一条报告就动手改一处。

## 我们确实碰到的问题

1. 选档案那个下拉框里多出来一个**一个存档都没有**的档案。以前这种空档案是不列出来的——列出来也没意义，选进去什么都干不了。现在它跟正常档案混在一起，很容易手滑选错。

2. 主题「跟随系统」这个设置坏了。我们先把主题切成了浅色，后来又切回跟随系统；系统这边明明是深色，界面却停在浅色不动了。刚打开程序那一下是对的（深色），只有自己手动再选一次跟随系统才露馅。

3. 换档案之后「手没洗干净」。我从一个档案切到另一个档案，切完那些操作卡上的 Open 按钮就已经是能点的了——照理说我还没在新档案里挑存档，那些按钮应该全是灰的。更让人不放心的是，这时候点进去改东西，它像是往**上一个**档案的存档里写。

4. 选卡车那个弹窗里，卡车前面的编号是从 0 开始的：0、1、2。以前一直是 1、2、3。名字和牌子都对，就是前面那个序号整体少了一。

5. 传送功能坏了。点 Apply 之后人确实动了，可到的地方不对、朝向也不对——看着像是「去哪儿」和「朝哪儿」这两样被对调了：我站到了原本该面朝的方向上，脸却朝着原本该站的位置。

6. 改里程那个弹窗，我在框里填了数，点 Apply，**什么都没发生**：没提示、没报错，里程也没变。反倒把框清空再点，像是走了一遍流程。这条我们最确定，因为试了好几次。

7. 改钱那个弹窗，金额框里预填的那个数比应有的**少了一位**。以前是一串八位的数，现在是七位。我们每次都得自己手动补一个零。

## 另外两件我们拿不准算不算毛病的事

8. 刚打开程序的时候，底下那条档案栏写着没找到档案、存档数是 0；可同一屏上面那个档案下拉框里明明列着两个档案。是档案没读进来，还是它就是要等你自己先选一个？

9. 改里程那个弹窗一打开，框里就写着 0。是不是它把我存档里的里程给清了？还是说这个框本来就默认填 0、要你自己输？

## 环境说明

- 这套东西跑的是它自己带的一个本地数据源，不需要外网；我们这边是断网试的。
- 浏览器窗口按 1440×900 试的，桌面尺寸；界面语言是英文。
- 上面全是使用者视角的原话。我们不会去翻代码，也没本事告诉你们原因在哪儿、该怎么改；仓库里那些说明文档我们也没看过。
