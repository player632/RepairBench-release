# 我们那个分色块的小游戏最近有好几处不对劲

我们几个人平时在手机上玩一个分色块的小游戏：一关是几列方块，颜色混着叠；点一列就把最上面同色的那几块拎起来，再点另一列就放过去，目标是把每一列都理成同一种颜色。关卡外面有一条 30 关的进度轨道，走到一定关数会解锁新玩法，还会给奖励；进关卡之前有个手把手的教程，右上角能重开这一关。它是装在手机上、断网也能玩的那种。最近它有好几处毛病，我们不懂代码，只能把看到的现象照实说出来，麻烦你们帮着查一查、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容，所以请你们自己把整套东西从头到尾过一遍，别只盯着我列出来的这几条。

## 我们确实碰到的问题

1. 进到关卡里面，屏幕最上面写着「Level 0」。我们明明玩的是第一关，怎么会是第 0 关？后面的关卡估计也都跟着少了一。

2. 关卡轨道最底下那个开始按钮，以前写的是「Play level 1」，现在只剩下「Level 1」，读起来不像个能按的按钮，倒像是个标签。

3. 点一列的时候，**被拎起来的高亮块比实际能拿的多一块**。有一列最上面只有一块红的，亮起来的却是两块；下面那块明明还压在别的颜色上，根本拿不走。

4. 走到一半刷新页面，或者关掉再打开，**刚才那一关的进度全没了**：直接被打回关卡轨道，走过的那一步也不认了。以前是会自动记住、回来还在那一关的。

5. 奖励那几档的关卡号全变了。以前是**第 4、7、10、16、25 关**给奖励，现在成了**第 4、8、11、18、28 关**。头一档没变，越往后差得越多。

6. 方块的**颜色不对了**：平时那套的红色变成了一种橙色，整盘看着像秋天那一套配色，可我们根本没去换主题。

7. 关卡轨道上，**我们还没通过的那一关，节点上已经画了「完成」的记号**。刚打开游戏、一关都没打，第一关就是完成状态。

## 另外两件我们拿不准算不算毛病的事

8. 点那种**一格都没有的空列**，什么反应也没有，不高亮也不提示。这是它本来就这样，还是哪儿坏了？

9. 点一列的时候，**一次亮起来好几块**，不是只亮最上面那一块。我们本来以为一次只能拿一块，这是故意这么设计的吗？

## 环境说明

- 这是个手机上的小游戏，我们是按**竖屏 430×932** 的尺寸在浏览器里试的。
- **全程断网**，不碰外网；断网能玩本来就是它的卖点，存进度走的是浏览器本地的存储。
- 上面全是使用者视角的原话。我们不翻代码，也没本事告诉你们原因在哪儿、该怎么改。
