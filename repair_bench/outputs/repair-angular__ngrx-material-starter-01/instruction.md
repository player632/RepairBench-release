# 修复任务：一个 Angular 材料风格仪表盘（starter 应用）

我把这个 Angular + ngrx 的 starter 应用跑在本地（构建产物静态托管，无外网）。之前它一切正常，现在好几个页面都出了问题。请帮我修好。

## 我确定的问题

1. **登录不上去了。** 点右上角的 "Sign in" 按钮没有任何反应，页面一直保持未登录状态；这也导致我没法去看那个只有登录用户才能访问的示例页。
2. **Todos 示例里回车添加失效。** 在输入框里敲好内容后按回车，条目不会被添加（点旁边的加号按钮倒是可以添加）。
3. **Todos 的筛选结果不对。** 我把筛选切到 "Active" 之后，列表里留下的条目明显不对，像是把该留的过滤掉了、把不该留的留下了。
4. **Todos 的撤销提示一闪而过。** 勾选或取消勾选某个条目后，底部会出现一个带 "Undo" 按钮的提示条，但它几乎瞬间就消失了，根本来不及点。
5. **Stocks 示例页打开时是空的。** 行情卡片要等我手动在输入框里敲一个代码之后才出现；我记得以前一进页面就会自动显示一条行情。
6. **用户管理示例的删除失效。** Simple state management 页面里，点用户卡片上的 Delete 按钮，用户并不会被移除。
7. **表单示例的自动保存不生效。** Form 页面里把 autosave 开关打开之后输入内容，感觉什么都没被保存下来。

## 我不确定的（可能是我的错觉）

8. Elements 示例页上那个计数器，帮我确认一下还能不能正常累加？我总觉得它有点不对。
9. 页脚里的外部链接（GitHub、Medium、Twitter 那些）点了没反应，能看看吗？

## 其他

还有些我说不上来的小毛病（个别页面上会出现没翻译的词条之类），请自己把每个页面都过一遍。最终预期：登录、设置（主题 / 夜间模式 / 顶栏 / 语言）、Todos、Stocks、书籍增删改查、用户管理、表单、通知、示例导航等全部功能都恢复正常，并且刷新页面后之前保存过的设置和数据还在。

另请留意：并非所有缺陷都会出现在上面的报告里；修复过程中破坏的既有行为同样会计入失分。
