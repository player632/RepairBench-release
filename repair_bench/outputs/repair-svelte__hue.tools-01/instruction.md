# 我们常用的那个颜色工具箱，最近好几处不对劲

我们内部天天用的是一套网页版的颜色工具：首页列出四个入口，分别是「混色」（把几个颜色混成一条色阶，可以选渐变色阶或者一个个色块，能调步数、混色模式和伽马值）、「颜色详情」（给一个颜色，列出它在各种色彩空间下的数值、互补色、以及一堆按这个颜色生成的外链和配色卡）、「混色模式」（两个颜色按十几种混合模式叠加）、「调色」（一个颜色配八个滑杆：变亮、变暗、去饱和、加饱和、旋转色相等等，右边实时给结果）。顶栏上有深浅色切换按钮和一个「Output format」下拉框，每个颜色还会显示一个颜色名字，页面上到处都是可以点开的取色器和可以复制的色卡。

最近升级完之后好几个地方不对劲。我们组没人会写前端，只能把眼睛看到的现象照实说出来，麻烦你们从头查一遍、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容，甚至根本不知道那是个毛病。所以请你们自己把整套东西从里到外过一遍，别只盯着我列出来的这几条改；修别的问题时弄坏的行为，同样会算在你们头上。

## 我们确实碰到的问题

1. 我们分享出去的混色链接（地址里明明写着 view=steps）打开以后不是一个个色块，而是一整条渐变；地址栏里的 view 还会自己变成 gradient。

2. 混色页右上角那个「加一个颜色」的圆按钮点了没反应：颜色数量不变，页面还是原来那两个色卡（可是地址栏里的 colors 参数好像多了一个）。要连点好几下、或者去动别的控件，新色卡才会突然出现。

3. 顶栏那个「Output format」下拉框选了没反应：切成 RGB 以后，页面上的颜色还是显示成 #0000ff 这种十六进制，刷新回来也还是 HEX。

4. 颜色详情页第 2 列「Color Spaces」里的 HSV 那一行数字不对：纯红 #ff0000 的 HSV 显示成「0.00, 1.00, 0.50, 1.00」，比正常的多了一节，而且和上面 HSL 那行一模一样。

5. 调色页把 Desaturate 拉到 50，右边 Result 那块颜色一点没变，还是原来的纯红；可是滑杆和数字框明明都显示 50，其他几个（Darken、Spin 之类）都正常生效。

6. 深色/浅色反了：我们系统是新开的窗口、没设过深色，页面却是深色的；点一下顶栏那个太阳/月亮按钮，反倒变回浅色。而且再点一下还是对不上。

7. 色卡上那个小魔棒按钮点开取色器以后，点页面别的地方关不掉它，非得再点一次那个按钮（或者点色卡外面很远的空白也没用）。

## 另外两件我们拿不准算不算毛病的事

8. 我们从别的地方复制了一个带 ?format=lab 的链接，打开以后颜色还是显示成 #ff0000 这种十六进制，地址栏里的 format 也自己变回了 hex。是不是链接带格式这个功能坏了一半、只做了一半没做完？要不要我们把它补上？

9. 调色页那 8 个滑杆里，只有 Spin 一个是 -360 到 360、单位是个度数符号，其他 7 个都是 0 到 100、单位是百分号。看起来像是 Spin 那个滑杆的配置写错了、或者单位漏改了。要不要我们把它统一成 0-100 和 % ？

## 环境说明

- 这个工具跑起来**不需要外网，也不需要任何后台服务**：所有数值都是浏览器里根据地址栏参数当场算出来的。我们这边是拔了网线试的，页面自己一个外部请求都没发出去，也没有弹新窗口；原来那几个外部字体、外部徽章图片和第三方统计脚本都已经换成本地的 inert 占位或者直接去掉了，所以任何「联网去取」的修法在这儿都不会生效，也不应该生效。
- 浏览器窗口是按 **1440×900** 试的，桌面尺寸，语言 en-US、时区 UTC。上面每一条现象都是在这个尺寸下看出来的，换个尺寸现象可能不一样。
- 每一项检查都是从一个**全新的页面**重新开始的：上一屏点过的按钮、开过的取色器、改过的下拉框都不会带到下一屏，本地存储里也不会留着上一次跑剩下的东西。所以「靠记住上次的状态蒙对」这种修法不管用。
- 页面里挂了一小段给自动化验收用的**只读探针**（记录页面有没有起来、有没有往外发请求、有没有报错，并且会先清掉这个工具自己持久化的那几个键），请**不要删掉它、不要改名、也不要让它去读写业务状态**；我们看不出你们动了它，但验收会。
- 上面全是使用者视角的原话。我们不会去翻代码，也没本事告诉你们原因在哪儿、该改哪个文件；哪几条是真毛病、哪几条本来就是设计如此（第 8、9 条就有可能是我们自己想多了），得你们自己判断。
- 改完以后整套东西还得能**照常打包出来**，别为了绕过现象把功能整块删掉、把滑杆去掉、把颜色写死成常量、或者按检查项做特判——那样我们会当成新毛病算在你们头上。
