# idle-xiuxian — 放置修仙游戏多处机制异常

我的放置仙途（idle-xiuxian）是一款浏览器单机修仙放置游戏（Vue 3 + Vite + Pinia + naive-ui）：玩家打坐修炼积攒修为、突破境界（练气、筑基……），炼制丹药（收集丹方残页合成完整丹方后按配方消耗灵草炼制），前往不同地点探索获取资源，抽卡获取装备与灵宠，用强化石强化装备，达成成就领取奖励。灵力由后台时钟持续产出，产出速率随突破提升；进度加密保存在浏览器本地数据库。项目在 `npm install` 之后用 `npm run build` 构建，产物输出到 `docs/` 目录，静态托管该目录即可运行，无后端、无运行时网络依赖。

QA 收集了一批玩家报告，引述如下。请注意：

- 大多数报告描述了真实、可复现的缺陷，各自有独立的根因；根因所在的文件可能与症状出现的界面不同。
- 至少有一份报告描述的是正常行为或环境误报，动手修改之前请先核实。
- 并非所有缺陷都有报告提及。修复过程中破坏的其他行为同样会计入失败。
- Not every defect is necessarily mentioned in the reports. Behaviors you break while fixing other things still count against you.

## 用户报告

1. **突破奖励变少了**：境界突破成功后发放的灵力奖励比我记忆里少，感觉只有原来的一半左右，其他突破后的变化看着正常。
2. **境界修为上限对不上**：突破到「练气二重」之后，修为上限比境界表里写的数值要高，后面的修炼节奏全乱了。
3. **新手村探索变贵了**：去「新手村」探索一次要消耗的灵力比以前多了，界面标的消耗数字也变了。
4. **强化扣石变多了**：装备从 +0 强化一级，实际扣掉的强化石比「每级 10 个」的既有规则多。
5. **成就奖励缩水**：「初获装备」成就达成后自动发放的灵力奖励比以前少了。
6. **打坐修炼变贵了**：现在点一次打坐修炼，扣的灵力比原来多。
7. **抽卡扣费与显示不符**：单抽按钮上明明写着 100 灵石，点一次实际扣了我 120 灵石。

另有两份报告经复核为误报或环境行为，不需要修复：

8. （诱饵）炼丹材料显示疑似异常：有玩家觉得炼丹界面里灵草的拥有数量显示有问题。经核实，材料拥有数与需求数的显示逻辑一直如此，属于正常显示。
9. （诱饵）存档疑似明文泄露：有玩家在浏览器本地存储里翻找，怀疑游戏存档以明文形式保存。经核实，存档本来就加密保存在浏览器本地数据库中，本地常规存储里没有存档数据属于正常现象。

## 验收口径

- 游戏在浏览器中正常启动，修炼、突破、炼丹、探索、抽卡、装备、成就各界面可用。
- 新存档的初始状态与设定一致（境界、修为、各类资源均为初始值）。
- 打坐修炼的灵力消耗与修为获取按当前境界的既定公式结算。
- 突破所需修为与突破后的境界名称、修为上限、灵力奖励、产出倍率按境界表与突破规则结算。
- 丹方残页按既定的合成规则积攒成完整丹方；已掌握丹方炼制时按配方消耗灵草，成功率受品阶与幸运影响。
- 探索的灵力消耗判定与扣减和地点配置一致。
- 抽卡的灵石扣费与界面标示的价格一致。
- 装备强化按既定的强化石成本与成功率规则结算。
- 成就达成判定与奖励结算符合成就定义。
- 敌人属性按既定的等级公式生成，同一输入结果稳定。
- 后台灵力时钟按既定频率与基础产出率驱动灵力增长。
- 存档加密保存与读取链路完好。
