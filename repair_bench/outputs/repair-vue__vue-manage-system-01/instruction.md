# 修复请求：后台管理系统

我们内部用的这套后台管理系统（纯前端、离线运行，数据都是本地模拟的）最近毛病很多，麻烦帮我修一下：

1. 登录越来越不对劲：输好用户名密码点登录，明明提示"登录成功"、页面也跳转了，但右上角看不到我的用户名；再去访问需要权限的页面或者刷新一下，就被踢回登录页，像没登录过一样。
2. 用 admin 账号登录后，左侧菜单少了一大片：只剩系统首页和系统管理下面的几项，组件、表格、图表、图标、主题、附加页面这些菜单全不见了，直接访问对应页面还提示没有权限。我们 admin 应该是全权限的。
3. 表单页的校验坏了：文本框是必填项吧？我什么都不填直接点"表单提交"，它不报任何错误，直接弹"提交成功！"。
4. 统计页里 CountUp 那一栏有个"更新数值"的计数器，正常情况页面打开约 5 秒后会从 1000 自动跳到 8000，现在等十来秒也一直停在原地不动。
5. 顶部标签栏的"标签选项"里有个"关闭其他"，本意是保留当前标签、关掉其余标签，现在效果正好反了：当前页的标签被关掉，其他标签反而都留着。
6. 侧边栏的折叠按钮坏了：页面打开时侧边栏是收起状态（窄窄一条），我点折叠按钮想把它展开，点了没任何反应，一直是收起的。
7. 注册页填完用户名、密码、邮箱点"注册"，提示注册成功之后没有跳回登录页，而是跳到一个错误页面去了。

另外两件顺带的事：

8. 有同事说 schart 图表页的图表好像渲染不出来，我自己看又觉得图都在。你帮我确认一下这个页是不是正常的，别是误报。
9. 还有人说首页的"时间线"卡片内容缺失，我看好像都在。也帮我确认一下，别误改。

要求：系统必须保持纯前端离线运行，不要引入任何联网请求；登录、退出、权限控制这套流程要修好，但别改变"未登录也能直接看系统首页"这个现状；本地模拟数据的结构不要动。

另请留意：并非所有缺陷都会出现在上面的报告里；修复过程中破坏的既有行为同样会计入失分。

## 验证方式说明

作答期间请不要自行运行项目的构建、开发服务器或测试来验证改动；会有单独的验证器重新构建并操作应用。请把精力放在阅读代码和定位根因上。
