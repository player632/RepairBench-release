# 修复任务：一个 Angular 画布编辑器（fabric.js 演示应用）

我把这个画布编辑器跑在本地（Angular + fabric.js 的演示应用，构建产物静态托管，无外网）。之前它一切正常，现在好几个功能都出了问题。请帮我修好。

## 我确定的问题

1. **加不了文字。** 在 "Add text" 输入框里敲好内容，点旁边的加号按钮，画布上什么都没有出现。
2. **Circle 按钮加出来的图形不对。** 点 "Add figure" 区域的 "Circle"，画布上出现的却是一个正方形。
3. **图层置顶按钮的行为是反的。** 选中一个元素后点 "Options" 区域里那个向上箭头图标（"Send to front"）按钮，元素没有到最上层，效果和我预期的相反。
4. **克隆失效。** 选中元素后点那个两份拷贝图标的克隆按钮，不会产生任何副本。
5. **自由绘制模式关不掉。** "Free Drawing Mode" 区域的开关默认是开着的，我点了好几次它都还是开着，没法切回普通的拖拽选择模式。
6. **保存/读取往返失效。** 画一个图形后点 "Save local"，再画一个新图形，然后点 "Load local"，画布并没有回到我保存时的状态。

## 我不确定的（可能是我的错觉）

8. 页面顶部的 GitHub 链接点了打不开，能帮我看看吗？

## 其他

还有些我说不上来的小毛病，请自己把每个功能区域都过一遍：图形按钮、文字样式（下划线 / 对齐这些）、尺寸输入框、透明度滑杆、左侧图片缩略图、颜色相关选项等等。最终预期：所有按钮和面板的行为都正确，画布状态与我的每一步操作一致。
