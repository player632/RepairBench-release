# 我们那个写文档的小工具最近有点乱

我们几个人平时用一个自己装在电脑上的写作小工具：左边一列最近打开的文档，中间写字，右边出预览，能嵌流程图，也能切到 JSON、YAML 这类结构化的文档去编辑。最近它有好几处不对劲。我们不懂代码，只能把看到的现象照实说出来，麻烦你们帮着查一查、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容，所以请你们自己把整套东西从头到尾过一遍，别只盯着我列出来的这几条。

## 我们确实碰到的问题

1. 左边那一列最近文档，我在某一条上点右键，会弹出一个小菜单。可我鼠标刚一按下去，菜单就自己消失了，里面那几项一个都点不着；重新右键再来一次，还是一样。等于说这个菜单是个摆设。

2. 文档里查找的时候，输入框旁边有翻匹配的两个小按钮，一个往前一个往后。我点往后的那个，它却跳到了上一个匹配；点往前的那个，反倒跳到下一个去了。方向整个是反的，连点两下就更糊涂了。

3. 我们的文档里会嵌流程图，就是在代码块的第一行写上图表类型的名字那种。名字全用小写的时候图能好好画出来；我一时手快把首字母打成了大写，图就不画了，那一块只当普通代码摆着。同一块内容，只改大小写，结果两样。

4. 右边预览里，我在一段话中间按了一次回车想换行，结果预览就真的断成了两行，一段话被切成好几截，整篇看着像楼梯。以前在一段里换行是不会断开的。

5. 我连着新开几个空白文档，它们的标题全都一模一样，末尾那个编号一直是 0；再开第三个、第四个也一样。我完全分不清哪个是哪个。

6. 我把当前文档切成 JSON 之后，右上角那三个显示模式的按钮就都变灰了，鼠标停上去还提示说这类文档没有预览——这我能理解。可是其中一个按钮看上去又像是被按住、选中的样子，又灰又亮，自己跟自己打架。

## 另外两件我们拿不准算不算毛病的事

7. 什么都没打开的时候，窗口中间只孤零零一行 “No file open”，底下四条快捷键提示，编辑和预览那一片全是空白。这是不是预览坏了、还是没加载出来？

8. 左边那个最近列表，一条都没有的时候只写着一句 “No recent files.”；等我开了文档，它角落里才冒出一个小数字。看着像是没加载完就停住了，是这样吗？

## 环境说明

- 这东西本来是个装在桌面上的小工具，我们这边是把它的网页那一面单独放在浏览器里试的，全程断网，不碰外网。
- 也正因为这样，真去读硬盘上的文件、往硬盘里存、复制到系统剪贴板、在文件管理器里定位这一类动作，在浏览器里本来就不通，界面上会给一句提示。这不算毛病，也不用去动它。
- 浏览器窗口按 1280×720 试的，桌面尺寸。
- 上面全是使用者视角的原话。我们不翻代码，也没本事告诉你们原因在哪儿、该怎么改。
