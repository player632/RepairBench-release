# 这套后台管理面板最近有好几处不对劲

我们几个人一直在用的那套后台管理面板（左边一条侧边栏，顶上一栏放着搜索框和几个小按钮，中间是各种表格、卡片和图表；表格上方有一个搜索框、几个筛选下拉和一个「显示哪些列」的按钮，表格底下有一条分页栏）最近有好几处看着不对劲。我不写代码，只能把眼睛看到的照实说出来，麻烦你们帮着查一查、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容；也有些地方我们以为是坏了、其实是它本来就该那样。所以请你们自己把整套东西从头到尾过一遍，别只盯着我列出来的这几条，也别看见一条报告就动手改一处。

## 我们确实碰到的问题

1. 任务列表那一页，表格底下那条分页栏整条不见了：既看不到「第几页、一共几页」的字样，也找不到上一页／下一页／首末页那些按钮。表格里的行倒是照常显示，数据看着是全的，就是底下那一条没了。

2. 工作台那一页打开是一片空白：本该在最上面的那四张数字卡片（营收、订阅、销量、当前活跃）一张都没有。上面那排标签看着是停在第二个上，可第二个本来就是灰的、底下也没有内容。

3. 顶栏那个搜索框（点开是一个下拉式的命令面板，里面列着各个页面）：我在里面挑了一个页面，面板是关上了，可页面根本没跳，还停在原来那一页。换几个条目试都一样。

4. 把界面语言切成中文，界面闪一下又自己弹回英文。语言菜单里两条选项都在，选英文是正常的，只有选中文会弹回来。

5. 顶栏那个外观弹层里，三个色彩模式按钮（浅色、深色、跟随系统）的高亮不对：加了粗描边的偏偏是我没在用的那两个，我自己当前在用的这个反而看着像没选中。

6. 有时候它会把我踢到登录页，地址栏里明明带着「登录完要回哪一页」的信息，可我登录完总是被扔到工作台，回不到原来那一页。

7. 新建任务的时候，标题里填一个再普通不过的短名字（六七个字母那种）也报「不合法」，对话框关不掉、任务也存不进去。以前这种名字是可以的，只有特别长的才会被拦下来。

## 另外两件我们拿不准算不算毛病的事

8. 在用户那一页点了右上角那个「Mock Loading」按钮以后，表格上会蒙一层加载提示，表格里的行和底下那条分页栏都会消失大约两秒钟；两秒以后行和分页栏又自己回来了。是不是分页被谁弄坏了、数据是不是中间丢了一下？

9. 工作台上面那四个标签页里，后面三个是灰的、点不动，只有第一个能点。是不是少买了授权，还是权限没配上？

## 环境说明

- 这套东西跑的是它自己带的一份本地数据，不需要外网；我们这边是断网试的。
- 浏览器窗口按 1280×720 试的，桌面尺寸；界面默认语言是英文。
- 上面全是使用者视角的原话。我们不会去翻代码，也没本事告诉你们原因在哪儿、该怎么改；仓库里那些说明文档我们也没看过。
