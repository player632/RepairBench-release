# 那个 React 学习站最近好几处不对劲

我们组内训在用的那个 React 学习站（首页一份课程目录，点进去是一篇一篇的教程，每篇底下带一块练习和一块参考答案，最后还有一个综合大练习）最近有好几个地方不对劲。我不懂代码，只能把看到的现象照实说出来，麻烦你们帮着查一查、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容，所以请你们自己把整套东西从头到尾过一遍（十一篇教程、每篇底下的两块练习、最后的大练习，一页一页都走一遍），别只盯着我列出来的这几条。

## 我们确实碰到的问题

1. 首页那份课程目录少了一条。原来是十一篇，现在只列出十条，而且最前面那篇「React 介绍」整条不见了，目录是从第一篇开始往下列的。

2. 每篇教程底下有「上一篇 / 回首页 / 下一篇」三格。我在第一篇那页看，底下写的下一篇是第三篇，点进去也果然是第三篇——中间第二篇被整个跳过去了。上一篇那一格倒是对的。

3. 左上角那个菜单按钮点下去完全没反应，左边那份课程目录抽屉压根不弹出来，怎么点都不出来，只能回首页去翻目录。

4. 教程底下中间那格「回首页」，点了以后没有回首页，反而跳到了最后一篇「结语」。首页明明就在目录里，可从教程页就是回不去。

5. 一篇教程拉到一半，点底下的「下一篇」，新那篇打开时页面还停在半中间，没有回到开头，每次都得自己手动滚上去。

6. 「理解 State」那篇的练习页，右边那块参考答案里有个加号按钮，点它数字一直是 0，怎么点都不动。

7. 最后那个综合大练习页，右边那个输入框里打字打不进去，一个字符都不显示；所以后面那个搜索按钮点了也没用，永远查不出任何公司数据。

## 另外两件我们拿不准算不算毛病的事

8. 教程页左边那块标着「你自己写」的区域，里面的按钮点了也完全没反应，数字也不动。这块是不是也坏了？（右边那块参考答案我们倒是能看见东西。）

9. 第一篇「React 介绍」那页往下翻到底，底下没有练习区——别的教程页都有「你自己写」和「参考答案」两块，就它一块都没有。是不是这一页的练习内容丢了？

## 环境说明

- 这套东西跑起来不需要外网，我们这边是断网试的；页面里那些公司数据都是它自己现算的，每次数字可能不一样，但栏目名称和格式是固定的。
- 浏览器窗口按 1440×900 试的，桌面尺寸。
- 上面全是使用者视角的原话，我们不会去翻代码，也没本事告诉你们原因在哪儿、该怎么改。
