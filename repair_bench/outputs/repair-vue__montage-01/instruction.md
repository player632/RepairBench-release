# 我们那个网页版视频剪辑台，最近好几处不对劲

我们内部用的是一个跑在浏览器里的视频蒙太奇剪辑台（Montage）：中间一块画布（可以选
预设尺寸、改背景色），左边一竖排标签页往里加东西——表情、形状、图片、文字、音频、
视频，还有设置；画布下面是图层列表、时间轴（每层一行，行两端可以拖裁剪把手）、
刻度尺和一根播放头；再下面是走带控制（播放/暂停、播放速度、导出格式）和一个时间
读数。选中画布上的元素以后，右侧还会出现对齐、排列（上移一层/下移一层之类）和画布
设置那几块面板。整套东西是 Vue 3 + TypeScript，画布用 fabric.js，构建是
`yarn run build`：先做一遍类型检查，再打包进 `dist/`，伺服的就是这个目录，所以
改了源码必须重新构建才看得见。它本来是套桌面壳子里的应用，但我们平时就在浏览器里
用它，导出那类要走桌面宿主的功能在浏览器里点了没反应，这一点我们都知道，算正常。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告
提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容，甚至根本不知道那是个
毛病。所以请你们自己把整套东西从里到外过一遍，别只盯着我列出来的这几条改；修别的
问题时弄坏的行为，同样会算在你们头上。

## 我们确实碰到的问题

1. 画布下面那个时间读数多出一段来。以前它是「分:秒.毫秒」的样子，比如刚打开时是
   `00:00.000`、走到一秒半是 `00:01.500`；现在开头硬生生多了一节，刚打开就成了
   `00:00:00.000`，看着像把小时也算进去了。读数本身还在走，就是格式变了，我们做
   字幕对时的时候总得多看两位，很容易看错。

2. 点播放以后，整个片子走得比真实时间慢一大截，感觉只有正常速度的十分之一左右：
   现实里过了十秒，时间读数才走一秒。暂停还是能停下来，走带按钮本身也没坏，速度
   那个选项我们没动过。以前播放是跟真实时间对得上的。

3. 时间读数对了，播放头却几乎不挪。我在时间轴上靠右的位置点一下，时间读数确实跳到
   了我点的那一秒，可是那根播放头只从左边挪了一丁点，大概只有它该走距离的十分之一，
   看着就像还停在开头。刻度尺、每层的行宽和位置都没变，只有播放头跟时间读数对不上。

4. 新加的东西跑到图层列表最底下去了。以前我从左边加一个表情或者一张图片，它会出现在
   列表最上面那一行（也就是最靠上的一层），现在加进来直接排到最后，我得一路往下翻才
   找得到。加的顺序本身是对的，就是每加一个都垫在最底下。

5. 在图层列表里点一行，画布上那个元素选不中。列表里那一行看着是响应了我的点击，可是
   画布上对应的元素没有出现选中框，也就没法接着拖它、对齐它或者调它的时长。用鼠标
   直接在画布上点那个元素倒是能选中，一切正常；只有从列表这一侧点进去不行。

6. 调图层顺序的时候，两边对不上。我选中一层去点上移/下移，画布上的叠放关系确实变了，
   可是左边图层列表里的行序一动不动，还是原来的顺序。列表顺序和画布上谁压着谁现在
   是两套说法，我们没法靠列表判断叠放。

7. 选中一个非视频的图层（图片、表情、形状都试过）以后按键盘上的上下方向键，本来应该
   每次给这一层的时长加或者减半秒，现在按了完全没反应，时长一格都不动。选中视频层的
   时候我们本来也不用这个快捷键，所以不好说是不是只有非视频这边坏了。

8. 每次打开都会弹一个紫色的提示，写着「🎉 Welcome to Montage!」，右上角出现，过一会儿
   自己消失。设置里翻遍了也找不到关它的开关。这是不是开发的时候忘了删的调试东西？
   要不要给它加个开关，或者干脆去掉？

9. 打开就是空的：图层列表那块写着「No layers added.」，时间轴上一行都没有，画布上什么
   元素也没有，得我自己从左边一个个往里加。是不是我们的工程文件没被加载出来？还是说
   它本来就该从一个空工程开始？

## 请你们照着修的时候，别动这些

上面第 8 条和第 9 条我们后来自己想明白了，那两处本来就是产品该有的样子：开屏那个欢迎
提示是它自己每次都会弹一次的问候，空工程也是它启动时的正常状态（它不预载任何示例工程，
所有东西都是用户自己往里加的）。这两条不用改，也不该改；如果你们为了让报告「闭环」而把
欢迎提示去掉、或者在启动时塞一个示例图层进去，那反而把好的行为改坏了。同样地，导出／
转码那一类要走桌面宿主的功能在浏览器里点了没反应是预期之内的，别去给它造假数据；左侧
字体列表现在读的是本地那份清单、图标样式也是随包本地提供的，这套离线供料方式请保持
原样，整个页面依然不许向外部网络要任何东西。修完以后 `yarn run build` 必须还能过
（它带类型检查），产物还得照常落在 `dist/`。
