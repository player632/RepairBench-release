# idle-wild-my-survival-saga — 荒野生存游戏多处机制异常

idle-wild-my-survival-saga 是一款浏览器单机放置类生存游戏（Vue 3 + Element Plus + Pinia + Vite）：玩家管理食物、水、木材等资源，进行采集、制作、建造、研究、探索与交易，学习技能树，完成任务并留意天气与季节变化。游戏内时间自动流逝，可暂停；进度加密保存在浏览器本地。项目在 `npm install` 之后用 `npm run build` 构建，产物输出到 `docs/` 目录，静态托管该目录即可运行，无后端、无网络依赖。

QA 收集了一批玩家报告，引述如下。请注意：

- 大多数报告描述了真实、可复现的缺陷，各自有独立的根因；根因所在的文件可能与症状出现的界面不同。
- 至少有一份报告描述的是正常行为或环境误报，动手修改之前请先核实。
- 并非所有缺陷都有报告提及。修复过程中破坏的其他行为同样会计入失败。

## 用户报告

1. **木材的储量上限不太对**：我拼命囤木材，发现木材最多只能存到 45 就再也涨不上去了。其他基础资源好像都能存更多，木材的上限像是被谁改小了。
2. **采集技能升级后经验曲线异常**：采集技能升到 2 级之后，下一级所需经验一下子涨得离谱，比以前版本陡得多，练级节奏完全变了。
3. **流浪商人迟迟不出现**：据说第 5 天左右会有流浪商人来交易，我一直等到第 5 天结束也没见到人影，交易面板里空空如也。
4. **技能树里明明经验够却学不了技能**：我攒够了经验想学采集系的第一个技能"高效采集"，按钮点了没反应，好像所需经验变高了。
5. **收集木材会莫名损失草药**：每次安排"收集木材"活动，完成结算时我的草药都会少一点。收集木材消耗的应该是干粮和水，跟草药有什么关系？
6. **同时开工的建筑比人手还多**：我只是一个人生存，第一个建筑还在施工，点第二个建筑它居然也立刻开工了。以前应该是排队等前一个完工才对。
7. **完成任务后物资不减反增**：交付任务"生存基础"（上交食物、水、木材）之后，我交出去的那些物资数量没有扣掉，反而变多了，像是账目记反了。

另有两份报告经复核为误报或环境行为，不需要修复：

8. （诱饵）季节显示疑似错乱：有玩家反映顶部季节指示不对。经核实，季节按固定周期轮转，当前天数对应的季节显示是正确的。
9. （诱饵）存档疑似损坏：有玩家在本地存储里看到一串看不懂的乱码，怀疑存档损坏。经核实，存档本来就是加密存储的，能看到加密字符串属于正常现象。

## 验收口径

- 游戏在浏览器中正常启动，时间、资源、活动、建筑、研究、探索、交易、任务、技能、成就各面板可用。
- 各资源的存储上限与设定一致。
- 技能升级所需经验按既定增长率递增。
- 商人按既定的天数窗口与周期出现。
- 技能树学习消耗的经验与技能定义一致。
- 采集活动消耗的资源与配方定义一致。
- 并行施工数量受玩家等级限制，超出部分排队。
- 研究消耗判定与科技成本一致。
- 任务完成时正确扣减目标物资并发放奖励。
- 季节显示与天数对应关系正确。
- 存档加密保存与读取链路完好。
