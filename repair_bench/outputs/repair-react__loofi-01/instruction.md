# 这个网页音乐播放器最近有点乱

我们自己搭的一个网页版音乐播放器（左边一列页签、上边一排播放按钮、底下常驻一条播放条那种）最近有好几个地方不对劲。我不懂代码，只能把看到的现象照实说出来，麻烦你们帮着查一查、修一修。

**先把话说在前面**：下面这些只是我们几个人平时用得到的部分，**并非所有缺陷都有报告提及**。有些毛病我们可能压根没注意到，或者不知道该怎么形容，所以请你们自己把整套东西从头到尾过一遍，别只盯着我列出来的这几条。

## 我们确实碰到的问题

1. 左边页签我连着切了两三个，然后点上边那个「后退」箭头，本来应该回到我刚才看的那一页，结果一下子跳回了最开头的首页，中间那一页整个被吃掉了。

2. 我在设置里挑了一个背景主题，当时确实换上了，挺好看。可只要一刷新页面，那块背景就变了样，不是我挑的那个了，每次进来都得重新点一遍。

3. 底下播放条上那个「下一首」按钮，点了完全没反应：歌没换，也没弹任何提示，按钮本身看着也不像是坏的。

4. 播放条右边那个总时长一直显示 00:00，换歌也一样，永远是 00:00。左边那个「已经播了多久」倒是会正常走。

5. 搜索页那个输入框旁边有个清空的小按钮。我点了它，框里的字一个都没少，还得自己一个一个删掉。

6. 我才切了**一个**页签，上边那个「后退」箭头就亮起来了、可以点。我记得刚打开、还没怎么切页的时候它应该是灰的、点不动的。

7. 设置里那个「下次接着上回那首歌继续」的开关，我明明打开了，当时看着也确实是开的；可关掉页面再进来，它又变回关的样子，好像完全没记住。

## 另外两件我们拿不准算不算毛病的事

8. 第一次打开的时候，音量条是空的（一点都没往上拉），旁边那个喇叭图标还是被划掉的静音样子。是不是音量初始化坏了？我们可没动过它。

9. 设置里还有一页是「实验性」的功能，里面那个「自动播放下一首」的开关，我把它关掉了，可下次再翻到这一页，它又是开着的。是不是没保存下来？

## 环境说明

- 这套东西是断网跑的，不需要外网；歌单是它自带的、固定的一份清单，每次打开都一样。
- 浏览器窗口按 1440×900 试的，桌面尺寸。
- 上面全是使用者视角的原话，我们不会去翻代码，也没本事告诉你们原因在哪儿、该怎么改。
